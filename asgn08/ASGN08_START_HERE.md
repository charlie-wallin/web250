# WEB-250 | asgn08: Active Record Directory — 100 points

**This starter ZIP overlays your existing asgn07 project.** It is **not** a complete working application. Your asgn07 `private/classes/Database.php`, `private/initialize.php`, other helper files, working database connection, images, and existing site navigation are not supplied or overwritten.

1. Work in the existing course Git repository. Create the required branch **`dev-active-record`** from the current `main` **before** starting asgn08.
2. Copy your **working asgn07** project to a new sibling directory **`web250/asgn08`**. Preserve asgn07 unchanged.
3. Extract the **contents** of this ZIP **into that new asgn08 directory**, not into a second nested `asgn08` directory.
4. Start with `public/sandbox_active_record.php`, which is complete and **ungraded**.
5. Implement the graded TODOs in `private/classes/Bird.php`, `public/birds.php`, and `public/bird.php`.
6. Update asgn08's `public/index.php`, README, and `.gitignore` as directed; merge your branch to `main`, push to GitHub, deploy to your webhost, and submit both URLs in **asgn08 Moodle Comments**.
7. Read `asgn08_active_record_directory.md` for the five-part tutorial, full requirements, and its **100-point rubric**.

**The separate Debugging Setup assignment is another 100 points.** It uses the separate `debugging_setup_student_starter.zip` and folder **`web250/debugging_setup`**, *not* `asgn08/debugging/`. No debugging files are in this asgn08 ZIP.
