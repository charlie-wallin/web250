# Start here - asgn07

Open `asgn07.md` and work through it in order.

This is a student starter, not a completed application. `Database.php` has a
TODO and `index.php` is a placeholder page. The Markdown tutorial supplies
the steps and code to complete them.

The SQL files and 17 JPEG teaching illustrations are already supplied.
The SQL uses three tables for a true many-to-many relationship and retains
compatible existing species records. It does not drop or truncate tables.
Back up existing work before an import.

The browser page for this assignment shows only a database-status table.
There is no bird listing, image display, resizing, CSS, filtering, or callback.

The JPEG files are AI-generated illustrations, not photographs. See
`public/images/birds/IMAGE-NOTES.md` for provenance and limitations.

After configuring PHP and MySQL, the local development server can be started
from this folder with `php -S localhost:8000 -t public`.

Never put real credentials in Git or in the submission ZIP. `.gitignore`
does not automatically exclude them from a manually created ZIP archive.
